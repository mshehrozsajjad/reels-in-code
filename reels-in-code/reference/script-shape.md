# Script shape: feeds, not films

The classic arc (setup → build-up → climax → wrap-up) loses people on a feed: they swipe during the setup and leave during the wrap-up. Instead:

- **Payoff first.** Open with the result or the boldest claim, in the first 2 seconds.
- **Hint every payoff** before it lands ("I'll show you how, and at the end…").
- **But / therefore,** never "and then". Each line should turn or push the previous one.
- **No gap after a payoff** — the next hook starts right away.
- **One peak, late.** The strongest line sits near the end.
- **No recap.** Don't summarise what they just watched.
- **Loop ending.** The last line should run straight back into the first one.
- **A reason to send it** (useful, surprising, or a "send this to…" moment). Only real ones.


## Hooks (always write 3)

Each hook: under 3 seconds spoken, true, and a different angle:
- **Result first**: show or state the finished outcome ("This reel never touched an editing app.")
- **Contrarian**: the common belief, flipped ("Editing apps are the slow way to make reels.")
- **Curiosity**: a specific detail that needs explaining ("I gave my editor one note. It's never made that mistake again.")

The first frame matters as much as the words: pick the most striking visual you have for second 0.

## Writing for speaking

- ~2.5 words per second. A 60 s reel is ~150 words.
- Short sentences. One idea per line.
- Keep the creator's phrasing; cut filler, don't add polish they wouldn't say.
- Each caption page ≈ one breath, ≤ 6 words. Pick one keyword per page: the word a viewer would remember.
